# Bharat Cap - Stock Picker POC

A unified stock discovery engine built with:
- **Backend**: Python/Flask + `nselib`
- **Frontend**: React + TypeScript + Tailwind

## Deployment Information
This Space is configured to build using the root `Dockerfile`, which:
1. Builds the React frontend.
2. Serves it via the Flask backend on port 7860.
